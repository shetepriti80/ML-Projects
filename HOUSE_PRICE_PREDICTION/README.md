# 🏠 House Price Prediction Using Machine Learning

## 📌 Project Description

This project is a **House Price Prediction System** developed using Machine Learning. The model predicts the price of a house based on various features such as area, number of bedrooms, bathrooms, location, and other property-related attributes.

The project follows the complete Machine Learning workflow, including data preprocessing, exploratory data analysis, model training, evaluation, and prediction.

## 🎯 Objectives

- Analyze and preprocess house price data.
- Identify important factors affecting house prices.
- Visualize relationships between different features.
- Train Machine Learning regression models.
- Evaluate model performance.
- Predict the price of a new house.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Models

The following regression algorithms can be used:

- Linear Regression
- Decision Tree Regression
- Random Forest Regression
- Gradient Boosting Regression

## 📊 Dataset

The dataset contains information about residential properties.

Typical features include:

- Area
- Bedrooms
- Bathrooms
- Parking
- Location
- Furnishing Status
- Price

The **Price** column is the target variable that the model predicts.
